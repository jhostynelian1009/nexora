# S10 — Glosario

| Término | Definición acordada |
|---|---|
| Nexora | Red social web estudiantil y de entretenimiento |
| Visitante | Persona sin sesión activa |
| Usuario | Cuenta registrada y autenticada |
| Perfil | Datos públicos básicos asociados a un usuario |
| Publicación | Contenido textual con imagen URL opcional |
| Feed | Lista cronológica de publicaciones |
| Like | Relación única que expresa aprobación de un usuario |
| Comentario | Respuesta textual asociada a publicación y usuario |
| Dashboard | Resumen visual de métricas globales y personales |
| JWT | Token firmado utilizado para autenticar solicitudes |
| SPA | Aplicación web que navega sin recargar documentos completos |
| API REST | Interfaz HTTP entre React y FastAPI |
| MVP | Producto mínimo funcional evaluable |
