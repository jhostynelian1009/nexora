## Términos y Definiciones v2

- **Cloudinary:** Servicio en la nube para la optimización, transformación y almacenamiento seguro de imágenes.
- **WebSocket (WS):** Protocolo de comunicación bidireccional sobre una única conexión TCP para eventos en tiempo real.
- **OTP (One-Time Password):** Código de un solo uso de 6 dígitos con expiración temporal para verificación de identidad.
- **Rate Limiting:** Mecanismo de control de frecuencia de peticiones HTTP para prevenir abuso o fuerza bruta.
- **Alembic:** Herramienta de migración de base de datos para SQLAlchemy en Python.
- **ConnectionManager:** Componente encubierto que gestiona las conexiones activas de sockets de los usuarios.
- **Followers / Following:** Relación asimétrica de seguimiento entre dos cuentas de usuario.
